# สคริปต์ทดสอบในเครื่อง (ไม่ขึ้นโฮสต์ — build-zip.sh ไม่รวม tools/)

ใช้กับเซิร์ฟเวอร์ในเครื่อง `php -S 127.0.0.1:8091 -t ~/Projects/sricodeboon-php-demo/htdocs` และบัญชีทดสอบ `tester` / `test1234` (มีเฉพาะฐานข้อมูลในเครื่อง)

| ลำดับ | ไฟล์ | ทำอะไร |
|---|---|---|
| 1 | `1-setup-seed.py` | ตั้งผู้ดูแลครั้งแรก (อ่าน setup_code จาก config.php) หรือล็อกอิน · ใส่ชั้น ป.4 นักเรียน 2 คน รายการ e1 · สร้าง PDF รายชื่อ/ใบรายชื่อ แล้วเช็กหน้า verify (คนทั่วไป/ครู/หลังย้ายสี) |
| 2 | `2-seed-staff.py` | ทำเนียบครู 11 ท่าน (ชื่อพร้อมยศแบบบนเว็บจริง) แบ่งสีแล้ว + หัวหน้าสี + ผู้ลงนามเกียรติบัตร |
| 3 | `3-seed-events.py` | รายการแข่งหลายชนิดกีฬา (กรีฑา ฟุตบอล วอลเลย์บอล กีฬาพื้นบ้าน) ไว้ทดสอบกรรมการตัดสิน |
| 4 | `4-all-docs.py` | สร้าง PDF ทั้ง 5 ชนิด (คำสั่ง รายชื่อ ใบรายชื่อ รายงาน เกียรติบัตร) นับหน้า หาตัวอักษรกล่อง และเช็ก verify ของคำสั่ง |

คำสั่งแต่งตั้งต้องร่างผ่านหน้าเว็บ (แท็บคำสั่ง → ร่างคำสั่งจากทำเนียบครู) เพราะตัวร่างอยู่ใน assets/order.js

ถ้าลบ `storage/kilasi.sqlite` ต้องรัน 1 → 2 → 3 ใหม่ (ไฟล์นี้ไม่ขึ้น git อยู่แล้ว ไม่ต้องลบก่อน commit)
ดูภาพ PDF: `pdftoppm -r 70 -png ไฟล์.pdf ชื่อ` · ตำแหน่งตัวอักษรจริง: `pdftotext -bbox`
