# ช้างเผือกเกมส์ · ระบบกีฬาสีภายใน

ระบบจัดการกีฬาสีภายในโรงเรียน ใช้ผ่านเบราว์เซอร์ ทำครั้งแรกให้ **โรงเรียนตำรวจตระเวนชายแดนช่างกลปทุมวันอนุสรณ์ 8** (สังกัด บก.ตชด.ภาค 2) โดย **ศรีโค้ดบูรณ์**

**ใช้งานจริง:** https://sricodeboon.infinityfreeapp.com/kilasi/

ครูหลายท่านช่วยกันกรอกรายชื่อ แบ่งสี และบันทึกผลแข่งจากมือถือของตัวเอง คะแนนรวมขึ้นจอฉายที่สนามทันที ผู้ปกครองเปิดดูตารางคะแนนได้โดยไม่ต้องสมัคร

## ความสามารถ

| แท็บ | ทำอะไรได้ |
|---|---|
| สรุปคะแนน | ตารางคะแนนรวมแบบสนามฟุตบอล เสื้อทีมพร้อมเลขอันดับ เหรียญทอง/เงิน/ทองแดง ผลล่าสุด และปุ่มเปิดจอฉาย |
| แบ่งสี | วางรายชื่อจาก Excel/Google Sheets แล้วแบ่งสีอัตโนมัติให้แต่ละชั้นได้จำนวนคนและชาย-หญิงใกล้เคียงกัน ตารางสรุปจำนวนต่อชั้นต่อสี |
| รายชื่อ | กรองตามชั้น สี ค้นชื่อ ย้ายสีรายคน คัดลอกไป Excel ดาวน์โหลด CSV และพิมพ์รายชื่อแยกสี |
| การแข่งขัน | เพิ่มรายการแข่งตามประเภท (กรีฑา กีฬาทีม กีฬาพื้นบ้าน กองเชียร์ ขบวนพาเหรด) · **กรอกคะแนนหรือเวลาของแต่ละสี ระบบจัดอันดับให้เอง** (คะแนนมากชนะ / เวลาน้อยชนะ รับ `12.5` หรือ `1:05.3` / เลือกอันดับเอง) · **รายชื่อผู้แข่งขัน** เลือกนักกีฬาแต่ละสี กรองตามระดับชั้นของรายการ พิมพ์ใบรายชื่อพร้อมช่องผลและลายมือชื่อกรรมการ · **จอแมตช์** |
| เกียรติบัตร | A4 แนวนอน ลายผ้าทรงทอง โลโก้ช้างเผือก เลขไทย · ออกให้ผู้ได้รับรางวัล หรือทุกคนในรายการ (คนอื่นได้ใบเข้าร่วม) และคณะสีที่ได้รางวัลคะแนนรวม · ตั้งผู้ลงนาม 2 คนและวันที่ · พิมพ์หรือบันทึกเป็น PDF ทีเดียวหลายใบ |
| ตั้งค่า | ชื่องาน โรงเรียน สังกัด ปีการศึกษา สีประจำทีม (2–8 สี) ครูหัวหน้าสี คะแนนต่อเหรียญ บัญชีครู เปลี่ยนรหัสผ่าน |

หน้าสำหรับวันงาน (เปิดจากแท็บสรุปคะแนน หรือเติมท้ายลิงก์)

- **จอฉายป้ายไฟ** `#board` พื้นมืด ตัวเลขเรืองแสงอ่านได้จากท้ายสนาม มีปุ่มเต็มจอ และกันจอดับ
- **จอฉายสนามหญ้า** `#pitch` การ์ดคะแนนบนสนามหญ้า น้องเผือกใส่เสื้อสีของทีมที่นำอยู่
- **พิธีมอบรางวัล** `#ceremony` แท่นรับรางวัล ๑ ๒ ๓ (ถ้ามี 2 สี เป็นชนะเลิศ/รองชนะเลิศ)
- **จอแมตช์** `#match-<รหัสรายการ>` (ปุ่ม “จอแมตช์” ในแต่ละรายการ) ป้ายคะแนนระหว่างแข่ง เช่น ฟุตบอล 2 : 1 ครูกด + / − จากมือถือ กด “จบการแข่งขัน” แล้วระบบบันทึกผลที่ 1 ที่ 2 ให้เอง

เมื่อมีแค่ 2 สี ระบบซ่อนเหรียญทองแดงให้เอง เพราะอันดับ 3 เกิดขึ้นไม่ได้

## ผู้ใช้และสิทธิ์

| ผู้ใช้ | ทำอะไรได้ |
|---|---|
| คนทั่วไป / ผู้ปกครอง (ไม่ต้องล็อกอิน) | ดูตารางคะแนน ผลแข่ง และจอฉาย **ไม่เห็นชื่อนักเรียน** (ระบบส่งไปแค่สีของแต่ละคนเพื่อนับจำนวน) |
| ครู | กรอก/แก้รายชื่อ แบ่งสี เพิ่มรายการแข่ง บันทึกผล |
| ผู้ดูแลระบบ | ทุกอย่างของครู + ตั้งค่างาน เพิ่ม/แก้/ลบบัญชีครู ตั้งรหัสผ่านใหม่ให้ครูที่ลืม ล้างข้อมูล |

## เริ่มใช้งาน (สำหรับผู้ดูแล)

1. เปิด https://sricodeboon.infinityfreeapp.com/kilasi/ ครั้งแรกจะเจอหน้า **ตั้งค่าระบบครั้งแรก**
2. กรอก **รหัสตั้งค่าระบบ** (อยู่ใน `config.php` ช่อง `setup_code` ผู้ติดตั้งแจ้งให้) ตั้งชื่อ ชื่อผู้ใช้ และรหัสผ่านของผู้ดูแล ทำได้ครั้งเดียว
3. แท็บ **ตั้งค่า** → ตรวจชื่องาน ชื่อโรงเรียน สี และคะแนน → **บัญชีครู** เพิ่มบัญชีให้ครูแต่ละท่าน แล้วแจ้งชื่อผู้ใช้และรหัสผ่าน
4. แท็บ **แบ่งสี** → วางรายชื่อ (บรรทัดละคน มีคอลัมน์ชั้นหรือเลือกชั้นก่อนวาง ระบบอ่านเพศจาก ด.ช./ด.ญ.) → กด **แบ่งเฉพาะคนที่ยังไม่มีสี**
5. แท็บ **การแข่งขัน** → เพิ่มรายการแข่งทั้งหมดก่อนวันงาน → กด **รายชื่อผู้แข่งขัน** เลือกนักกีฬาแต่ละสี → **พิมพ์ใบรายชื่อผู้แข่งขัน** ให้กรรมการ
6. วันงาน: เครื่องที่ต่อโปรเจกเตอร์เปิดลิงก์ที่ลงท้าย `#board` แล้วกด **เต็มจอ** ครูกรรมการกรอกคะแนน/เวลาจากมือถือที่แท็บการแข่งขัน (กีฬาทีมใช้ **จอแมตช์** กด + ทุกครั้งที่ได้ประตู)
7. หลังแข่ง: แท็บ **เกียรติบัตร** → ใส่ผู้ลงนามและวันที่ → เลือกรายการ → **พิมพ์ / บันทึกเป็น PDF**

รูปแบบรายชื่อที่วางได้ (คัดลอกจาก Excel ได้ตรง ๆ คอลัมน์คั่นด้วยแท็บหรือจุลภาค)

```
ป.4	1	ด.ช.ธนกร ใจดี
ป.4	2	ด.ญ.ปริยา ศรีสุข	ญ
1 ด.ช.ภูมิ แสนดี          ← ไม่มีคอลัมน์ชั้น ใช้ชั้นที่เลือกไว้
```

### ข้อมูล

เก็บเป็นเอกสาร JSON ในตาราง `docs` รูปเดียวกับที่หน้าแอปใช้

| เอกสาร | เนื้อหา |
|---|---|
| `config/main` | `eventName` `school` `affiliation` `year` `points{g,s,b}` `colors[{id,name,hex,teacher}]` `cert{s1n,s1p,s2n,s2p,date}` (ผู้ลงนามและวันที่ในเกียรติบัตร) |
| `classes/<id>` | `name` (เช่น ป.4 หรือ ป.4/1) `students[{id,no,name,sex,color}]` |
| `events/<id>` | `name` `cat` `level` `order` `g` `s` `b` (id ของสีที่ได้ที่ 1 2 3) `at` · `scoring` (`high` `low` `manual`) `score{สี:ค่า}` `status` (`live` `done`) `entries{สี:[รหัสนักเรียน]}` |

ตารางอื่น: `teachers` (รหัสผ่านเก็บด้วย `password_hash`) · `meta.rev` เลขรอบข้อมูล เพิ่มทุกครั้งที่บันทึก หน้าจอถาม `state&since=rev` ทุก 4 วินาที (จอฉายทุก 2 วินาที) ถ้าไม่มีอะไรเปลี่ยนเซิร์ฟเวอร์ตอบสั้น ๆ · `login_fails` ใส่รหัสผิดเกิน 8 ครั้งใน 10 นาทีต่อ IP ต้องรอ

### ความปลอดภัย

- ทุกคำขอ POST ต้องมี `X-CSRF-Token` (419 → หน้าแอปขอ token ใหม่แล้วลองซ้ำ 1 ครั้ง)
- `.htaccess` กัน `config.php` `*.sqlite` `README.md` และโฟลเดอร์ `lib/` `storage/`
- การตั้งค่าครั้งแรกต้องใช้ `setup_code` กันคนอื่นเปิดก่อนแล้วยึดบัญชีผู้ดูแล
- ครูแก้ค่าตั้งงานและจัดการบัญชีไม่ได้ · ลบหรือลดสิทธิ์บัญชีตัวเองไม่ได้

## รันในเครื่อง

ต้องมี PHP 8.1 ขึ้นไป พร้อม pdo_sqlite

```bash
git clone https://github.com/sricodeboon/kilasi.git
cd kilasi
php -S 127.0.0.1:8080
# เปิด http://127.0.0.1:8080/  (ไม่มี config.php ใช้ config.sample.php ซึ่ง setup_code ว่าง = ไม่ต้องใส่รหัส)
```

PHP built-in server ไม่อ่าน `.htaccess` การกันไฟล์ลับต้องตรวจบนโฮสต์จริง

## ขึ้นโฮสต์ (InfinityFree)

1. สร้าง `config.php` จาก `config.sample.php` แล้วตั้ง `setup_code` เป็นรหัสสุ่ม
2. zip โฟลเดอร์ (ชื่อโฟลเดอร์ในไฟล์ zip ต้องเป็น `kilasi/`) โดยไม่รวมฐานข้อมูลในเครื่อง ไฟล์ git และคู่มือ
   ```bash
   cd .. && zip -qr -X kilasi.zip kilasi -x "*.DS_Store" "kilasi/.git/*" "kilasi/.gitignore" "kilasi/storage/*.sqlite*" "kilasi/README.md" "kilasi/LICENSE"
   ```
3. File Manager → Upload Files → Zip & Extract ในโฟลเดอร์ `/htdocs` (ไฟล์ .php อัปแบบไฟล์เดี่ยวไม่ผ่าน ต้องใช้ zip)
4. ตรวจว่า `/kilasi/config.php` `/kilasi/lib/` `/kilasi/storage/` เปิดจากภายนอกไม่ได้ (403)
5. อัปเดตรอบต่อไป zip ใหม่โดย **ไม่ต้อง** รวม `config.php` ถ้าไม่ได้เปลี่ยน และห้ามทับ `storage/` บนโฮสต์

สำรองข้อมูล: ดาวน์โหลด `storage/kilasi.sqlite` จาก File Manager
