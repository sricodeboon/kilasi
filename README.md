# ช้างเผือกเกมส์ · ระบบกีฬาสีภายใน

ระบบจัดการกีฬาสีภายในโรงเรียน ใช้ผ่านเบราว์เซอร์ ทำครั้งแรกให้ **โรงเรียนตำรวจตระเวนชายแดนช่างกลปทุมวันอนุสรณ์ 8** (สังกัด กก.ตชด.23) โดย **ศรีโค้ดบูรณ์**

**ใช้งานจริง:** https://sricodeboon.infinityfreeapp.com/kilasi/

ครูหลายท่านช่วยกันกรอกรายชื่อ แบ่งสี และบันทึกผลแข่งจากมือถือของตัวเอง คะแนนรวมขึ้นจอฉายที่สนามทันที ผู้ปกครองเปิดดูตารางคะแนนได้โดยไม่ต้องสมัคร

## ความสามารถ

| รายชื่อ | กรองตามชั้น สี ค้นชื่อ ย้ายสีรายคน คัดลอกไป Excel ดาวน์โหลด CSV และพิมพ์รายชื่อแยกสี |

## โหมดกรรมการและแอปบนมือถือ

ครูกรรมการบันทึกผลจากมือถือด้วยการแตะ ไม่ต้องพิมพ์ เปิดจากปุ่ม **บันทึกผล** ที่หัวเว็บ หรือลิงก์ `…/kilasi/#judge`

| ชนิดการบันทึก | ใช้กับ | วิธีบันทึก |
|---|---|---|
| แตะตามลำดับ | กรีฑา กีฬาพื้นบ้าน | แตะสีตามลำดับที่เข้าเส้นชัย (2 สีแตะครั้งเดียว ระบบใส่ที่ 2 ให้เอง) |
| นับประตู + จุดโทษ | ฟุตบอล ฟุตซอล แชร์บอล | กด + ทุกประตู สลับครึ่งแรก/ครึ่งหลัง เสมอแล้วบันทึกจุดโทษ เข้า ✓ / พลาด ✗ ผลบันทึกแบบ `1 (3) : 1 (2)` |
| นับเซต | วอลเลย์บอล (2 ใน 3 เซต เซตละ 25 เซตสุดท้าย 15) ตะกร้อ (2 ใน 3 เซต เซตละ 21 ไม่เกิน 25) | กด +1 ทุกแต้ม ระบบปิดเซตเมื่อถึงแต้มและนำ 2 ชนะครบเซตแล้วจบแมตช์เอง |
| นับเอนด์ | เปตอง (ถึง 13 แต้ม) | จบแต่ละเอนด์แตะสีที่ได้แต้ม แล้วแตะจำนวนแต้ม 1–6 |
| คะแนนกรรมการ | กองเชียร์ ขบวนพาเหรด | แป้นตัวเลขกรอกคะแนนทีละสี |

ระบบเลือกชนิดให้เองจากประเภทและชื่อรายการ (มีคำว่า วอลเลย์/ตะกร้อ/เปตอง) · บันทึกแล้วมีหน้าสรุปพร้อม **ย้อนกลับได้ภายใน 15 วินาที** และปุ่ม **รายการถัดไป** · ระหว่างแข่งกด “ย้อนกลับ 1 ขั้น” ได้ถ้ากดผิด

**ติดตั้งเป็นแอป (PWA)** ไม่ต้องผ่าน Play Store/App Store เปิดเว็บด้วย Chrome (Android) แล้วกด **ติดตั้งแอป** ในโหมดกรรมการ หรือเมนู ⋮ → ติดตั้งแอป · iPhone เปิดด้วย Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม · แอปเปิดที่หน้าโหมดกรรมการ มีทางลัด บันทึกผล / จอฉายป้ายไฟ / ตารางคะแนน (`manifest.webmanifest` `sw.js`) ข้อมูลคะแนนดึงสดจากเซิร์ฟเวอร์เสมอ ต้องมีอินเทอร์เน็ตตอนบันทึก

## เอกสาร PDF (mPDF) และตรวจสอบด้วย QR

เอกสารทุกชนิดมี QR ตรวจสอบ รหัสเอกสาร และลิงก์ตรวจสอบที่ท้ายหน้า สร้างเป็นไฟล์ PDF ที่เซิร์ฟเวอร์ด้วย [mPDF](https://mpdf.github.io/) ไม่ใช้หน้าต่างพิมพ์ของเบราว์เซอร์ (`pdf.php` ครูที่ล็อกอินเท่านั้น) กดแล้วขึ้นกล่อง **เปิด PDF / ดาวน์โหลด**

| เอกสาร | ปุ่ม | รูปแบบ |
|---|---|---|
| รายงานผลการแข่งขัน | สรุปคะแนน → รายงานผล PDF + QR | ฟอนต์ราชการ TH Sarabun New · A4 แนวตั้ง สรุปคะแนนรวม ผลทุกรายการแยกประเภท กรรมการตัดสินใต้ตารางแต่ละประเภท ลงนามครูใหญ่แบบคำสั่ง QR หัวกระดาษ เลขหน้า |
| เกียรติบัตร | เกียรติบัตร → สร้าง PDF เกียรติบัตร | A4 แนวนอน กรอบทองลายผ้าทรง โลโก้ช้างเผือก QR รายใบ (ไม่เกิน 300 ใบต่อครั้ง) |
| ใบรายชื่อผู้แข่งขัน | การแข่งขัน → รายชื่อผู้แข่งขัน → PDF ใบรายชื่อผู้แข่งขัน + QR | ฟอนต์ราชการ TH Sarabun New 16 พอยต์ · A4 แยกสี ช่องผลและลายมือชื่อกรรมการ · ลงนามกรรมการตัดสิน (ถ้าตั้งไว้) และครูใหญ่พร้อมชื่อ · QR หัวกระดาษ |
| รายชื่อคณะครูและนักกีฬา | รายชื่อ → PDF รายชื่อ + QR | ฟอนต์ราชการ TH Sarabun New 16 พอยต์ · ตามตัวกรองชั้น/สี/ค้นชื่อ เลือก “ทุกสี” จะแยกสีละหน้า (คณะครูของสีนั้น หัวหน้าสีขึ้นก่อน แล้วนักกีฬา จำนวนชาย-หญิง) มีคณะครูเมื่อไม่กรองชั้น QR หัวกระดาษทุกหน้า · ลงนามครูใหญ่ท้ายทุกสี |
| คำสั่งแต่งตั้งคณะกรรมการ | คำสั่ง → PDF คำสั่ง + QR | ตามระเบียบงานสารบรรณ: TH Sarabun New 16 พอยต์ ระยะบรรทัดเดี่ยว ครุฑสูง 3 ซม. ห่างขอบบน 1.5 ซม. ขอบซ้าย 3 ซม. ขวา 2 ซม. เลขไทย เลขหน้า “- ๒ -” กลางบนตั้งแต่หน้า 2 · QR และรหัสเอกสารท้ายทุกหน้า |

- **ช่องลงนามในใบรายชื่อ** รูปแบบเดียวกับคำสั่ง: ไม่มีคำว่า ลงชื่อ และเส้นจุด ยศเต็มชิดหน้าชื่อบนบรรทัดลงลายมือชื่อ ชื่อในวงเล็บไม่มียศ ตำแหน่งกึ่งกลางใต้ชื่อ (`pdf_sign_official`)
- **ชื่อครูใหญ่ในช่องลงนาม** ใช้ผู้ลงนามเกียรติบัตรคนที่ 1 → ถ้าไม่ได้ตั้ง ใช้ผู้ลงนามในคำสั่ง → คนแรกในทำเนียบครู (`principal_name`)
- **ตัดคำไทย** ใช้ตัวตัดคำ ICU ของ PHP (`IntlBreakIterator`, ส่วนขยาย intl) แทรกจุดตัดระหว่างคำก่อนส่งให้ mPDF (`thai_lbr` ใน `lib/pdf.php`) เพราะพจนานุกรมของ mPDF ตัดบางคำผิด เช่น “งา|น” · ข้อความสั้นในเครื่องหมายคำพูดไม่ถูกตัดกลาง · ถ้าโฮสต์ไม่มี intl จะกลับไปใช้พจนานุกรมของ mPDF (ดูได้จาก header `X-Thai-Linebreak` ของ pdf.php)
- คำสั่ง (หนังสือราชการ) ใช้ฟอนต์แห่งชาติ **TH Sarabun New** (GPL-2.0+ พร้อมข้อยกเว้นฟอนต์ ดู `fonts/LICENSE-THSarabunNew.txt`) เอกสารอื่นใช้ Sarabun
- ฟอนต์ Sarabun และ Chonburi (OFL) ที่ `fonts/` เพิ่มอักขระ U+200B แบบว่างด้วย `tools/patch-fonts.py` เพราะ mPDF แทรกอักขระนี้เป็นจุดตัดคำภาษาไทย (ตัดคำด้วยพจนานุกรม `useDictionaryLBR`) ถ้าฟอนต์ไม่มีจะเห็นเป็นกล่อง
- กรอบเกียรติบัตรและโลโก้เป็นภาพที่ `assets/pdf/` · QR ใช้ `<barcode type="QR">` ของ mPDF (แพ็กเกจ mpdf/qrcode)
- **QR ตรวจสอบ** ตอนสร้างเอกสาร เซิร์ฟเวอร์เก็บสำเนาเอกสารในตาราง `reports` พร้อมรหัส 10 ตัว (เช่น `D588-JBA3-97`) และลายนิ้วมือของผลการแข่งขัน ณ เวลานั้น สแกนแล้วเปิด `verify.php?r=รหัส` (เกียรติบัตร `&n=ลำดับ`) ไม่ต้องล็อกอิน บอกว่า ✓ ออกจากระบบจริง ใครออก เมื่อไร · ✓ ผลยังตรงกับระบบ หรือ ! มีการแก้ไขผลหลังพิมพ์ · ✕ ไม่พบเอกสาร ถ้ารหัสปลอม
- **เอกสารรายชื่อ** (ใบรายชื่อผู้แข่งขัน รายชื่อคณะครูและนักกีฬา) ลายนิ้วมือคือรายชื่อที่พิมพ์ (ชื่อ ชั้น สี หัวหน้าสี) หน้าตรวจสอบบอกว่ารายชื่อยังตรงกับระบบ หรือมีการเพิ่ม/ลบ/ย้ายสีหลังพิมพ์ · คนทั่วไปเห็นแค่จำนวนแยกสี ครูที่ล็อกอินเห็นรายชื่อเต็ม (ไม่เปิดชื่อนักเรียนต่อสาธารณะ เหมือนหน้าแอป)

หน้าสำหรับวันงาน (เปิดจากแท็บสรุปคะแนน หรือเติมท้ายลิงก์)

- **จอฉายป้ายไฟ** `#board` พื้นมืด ตัวเลขเรืองแสงอ่านได้จากท้ายสนาม มีปุ่มเต็มจอ และกันจอดับ
- **จอฉายสนามหญ้า** `#pitch` การ์ดคะแนนบนสนามหญ้า น้องเผือกใส่เสื้อสีของทีมที่นำอยู่
- **พิธีมอบรางวัล** `#ceremony` แท่นรับรางวัล ๑ ๒ ๓ (ถ้ามี 2 สี เป็นชนะเลิศ/รองชนะเลิศ)
- **จอแมตช์** `#match-<รหัสรายการ>` (ปุ่ม “จอแมตช์” ในแต่ละรายการ) ป้ายคะแนนระหว่างแข่ง เช่น ฟุตบอล 2 : 1 ครูกด + / − จากมือถือ กด “จบการแข่งขัน” แล้วระบบบันทึกผลที่ 1 ที่ 2 ให้เอง

เมื่อมีแค่ 2 สี ระบบซ่อนเหรียญทองแดงให้เอง เพราะอันดับ 3 เกิดขึ้นไม่ได้

## คณะกรรมการตัดสินแยกตามชนิดกีฬา

แท็บ **การแข่งขัน** → แผง **คณะกรรมการตัดสิน** → **จัดกรรมการตัดสิน** (ผู้ดูแลแก้ ครูทุกคนดูได้)

- ระบบจัดกลุ่มรายการเป็นชนิดกีฬาให้เอง: กีฬาประเภททีมแยกตามชื่อกีฬา (ฟุตบอล ชาย/หญิง = ฟุตบอล) ประเภทอื่นรวมตามประเภท (กรีฑา กีฬาพื้นบ้าน)
- ใส่ชื่อกรรมการ (เลือกจากทำเนียบครู) และตำแหน่ง ประธาน / รองประธาน / กรรมการ / กรรมการและเลขานุการ
- ชื่อไปขึ้นใน **คำสั่งแต่งตั้ง** (ฝ่ายตัดสินการแข่งขัน ข้อย่อยต่อจากรายชื่อฝ่าย) · **รายงานผล PDF** (ใต้ตารางแต่ละประเภท) · **ใบรายชื่อผู้แข่งขัน** (ช่องลงนามกรรมการตัดสินของชนิดกีฬานั้น) · หน้าตรวจสอบ QR ของเอกสารเหล่านั้น
- ข้อมูลอยู่ที่ `config.judges` คนที่ไม่ได้ล็อกอินไม่ได้รับจาก API · ชนิดกีฬาคำนวณด้วย `sportKey()` (assets/judges.js) และ `sport_key()` (lib/report.php) ต้องตรงกัน

## คำสั่งแต่งตั้งคณะกรรมการ

แท็บ **คำสั่ง** (ผู้ดูแลแก้ไข ครูทุกคนพิมพ์ได้)

1. กด **ร่างคำสั่งจากทำเนียบครู** ระบบสร้างคณะกรรมการ 9 ฝ่าย (อำนวยการ ดำเนินงาน ครูประจำสี สถานที่และอุปกรณ์ พิธีการและประชาสัมพันธ์ ตัดสินการแข่งขัน พยาบาล รางวัลและเกียรติบัตร ประเมินผลและรายงาน) พร้อมหน้าที่ และกระจายชื่อครูให้ (ผู้ลงนามเกียรติบัตรคนที่ 1 หรือคนแรกในทำเนียบเป็นครูใหญ่ ประธานอำนวยการ และผู้ลงนาม)
2. แก้เลขที่ วันที่สั่ง เรื่อง ข้อความนำ ชื่อฝ่าย หน้าที่ กรรมการและตำแหน่ง (ประธาน รองประธาน กรรมการ กรรมการและเลขานุการ กรรมการและผู้ช่วยเลขานุการ) เพิ่ม/ลบ/เลื่อนฝ่ายได้
3. **ฝ่ายครูประจำสี** ดึงจากแท็บแบ่งสีตอนพิมพ์ หัวหน้าสีขึ้นก่อน
4. รูปแบบตามคู่มือการพิมพ์หนังสือตามระเบียบงานสารบรรณ: เลขที่คำสั่งทับปี พ.ศ. ที่ออกคำสั่ง (ไม่ใส่เลขที่จะเว้นช่องให้เติม) · เส้นทึบใต้ส่วนหัว · “สั่ง” ตรงกับคำ “ตั้งแต่” ในบรรทัด ทั้งนี้ ตั้งแต่… · วันที่แบบ ๒๘ กันยายน พ.ศ. ๒๕๖๙ · ชื่อเต็มห่างจากบรรทัด สั่ง ณ วันที่ ๓ บรรทัด ชื่อกับตำแหน่งกึ่งกลางใต้บรรทัดวันที่
4. ผู้ลงนามที่มียศ (เช่น พ.ต.ท.สมชาย ใจดี) ระบบพิมพ์ยศเต็ม “พันตำรวจโท” ไว้หน้าลายมือชื่อ (บรรทัดเหนือชื่อ ไม่มีเส้นจุด) และชื่อในวงเล็บไม่มียศ “(สมชาย  ใจดี)” ตามระเบียบงานสารบรรณ รองรับยศตำรวจ ทหาร และยศหญิง (`split_rank` ใน `lib/report.php`)
5. กด **PDF คำสั่ง + QR** · หน้าตรวจสอบบอกว่าคำสั่งยังตรงกับระบบ หรือมีการแก้ไขหลังพิมพ์ แสดงรายชื่อคณะกรรมการ (ไม่มีข้อมูลนักเรียน)

ข้อมูลอยู่ที่ `config.order` คนที่ไม่ได้ล็อกอินไม่ได้รับข้อมูลนี้จาก API · ตราครุฑจาก Wikimedia Commons (สาธารณสมบัติ) ที่ `assets/pdf/garuda.png`

### ทำเนียบครู (จาก Q-Info)

แท็บ **ตั้งค่า → บัญชีครู** มีตาราง **ทำเนียบครู** รายชื่อครูทั้งโรงเรียนที่นำเข้าจากหน้าผู้ใช้ของ Q-Info (ชื่อ-สกุล ครูประจำชั้น ชื่อผู้ใช้ Q-Info)

- กด **สร้างบัญชี** ระบบเติมชื่อและชื่อผู้ใช้ (ตัวพิมพ์เล็กแบบเดียวกับ Q-Info) ให้ ผู้ดูแลใส่รหัสผ่านเองแล้วกด เพิ่มบัญชี · ครูที่มีบัญชีแล้วขึ้น “มีแล้ว”
- แก้ชื่อในช่องได้ เช่น ใส่ยศตำรวจ ชื่อที่แก้จะใช้ในช่องเลือกอื่นด้วย
- ช่อง **ครูหัวหน้าสี** และ **ผู้ลงนามเกียรติบัตร** เลือกชื่อจากทำเนียบได้ (พิมพ์แล้วขึ้นรายชื่อ)
- **แบ่งครูเข้าสี** แท็บ **แบ่งสี** → ส่วน **คณะครูประจำสี** กด “แบ่งเฉพาะครูที่ยังไม่มีสี” ระบบให้แต่ละสีมีครูเท่ากันและชาย-หญิงใกล้เคียงกัน (อ่านเพศจากคำนำหน้า นาง/นางสาว/หญิง) ย้ายรายคนได้ที่ช่องสี กด “ตั้งเป็นหัวหน้าสี” ได้สีละคน · ตารางคะแนนขึ้นจำนวนครูและหัวหน้าสี · แท็บรายชื่อและ PDF รายชื่อแสดงคณะครูของสีที่เลือก
- คนที่ไม่ได้ล็อกอินไม่เห็นทำเนียบ ครูเห็นเฉพาะชื่อ ชื่อผู้ใช้ Q-Info เห็นเฉพาะผู้ดูแล

## เริ่มใช้งาน (สำหรับผู้ดูแล)

1. เปิด https://sricodeboon.infinityfreeapp.com/kilasi/ ครั้งแรกจะเจอหน้า **ตั้งค่าระบบครั้งแรก**
2. กรอก **รหัสตั้งค่าระบบ** (อยู่ใน `config.php` ช่อง `setup_code` ผู้ติดตั้งแจ้งให้) ตั้งชื่อ ชื่อผู้ใช้ และรหัสผ่านของผู้ดูแล ทำได้ครั้งเดียว
3. แท็บ **ตั้งค่า** → ตรวจชื่องาน ชื่อโรงเรียน สี และคะแนน → **บัญชีครู** เพิ่มบัญชีให้ครูแต่ละท่าน แล้วแจ้งชื่อผู้ใช้และรหัสผ่าน
4. แท็บ **แบ่งสี** → วางรายชื่อ (บรรทัดละคน มีคอลัมน์ชั้นหรือเลือกชั้นก่อนวาง ระบบอ่านเพศจาก ด.ช./ด.ญ.) → กด **แบ่งเฉพาะคนที่ยังไม่มีสี**
5. แท็บ **การแข่งขัน** → เพิ่มรายการแข่งทั้งหมดก่อนวันงาน → กด **รายชื่อผู้แข่งขัน** เลือกนักกีฬาแต่ละสี → **พิมพ์ใบรายชื่อผู้แข่งขัน** ให้กรรมการ
6. วันงาน: เครื่องที่ต่อโปรเจกเตอร์เปิดลิงก์ที่ลงท้าย `#board` แล้วกด **เต็มจอ** ครูกรรมการกรอกคะแนน/เวลาจากมือถือที่แท็บการแข่งขัน (กีฬาทีมใช้ **จอแมตช์** กด + ทุกครั้งที่ได้ประตู)
7. หลังแข่ง: แท็บ **เกียรติบัตร** → ใส่ผู้ลงนามและวันที่ → เลือกรายการ → **พิมพ์ / บันทึกเป็น PDF**

รูปแบบรายชื่อที่วางได้ (คัดลอกจาก Excel ได้ตรง ๆ คอลัมน์คั่นด้วยแท็บหรือจุลภาค)

```
ป.4	1	ด.ช.ธนกร ใจดี
ป.4	2	ด.ญ.ปริยา ศรีสุข	ญ
1 ด.ช.ภูมิ แสนดี          ← ไม่มีคอลัมน์ชั้น ใช้ชั้นที่เลือกไว้
```

### ความปลอดภัย

- ทุกคำขอ POST ต้องมี `X-CSRF-Token` (419 → หน้าแอปขอ token ใหม่แล้วลองซ้ำ 1 ครั้ง)
- `.htaccess` กัน `config.php` `*.sqlite` `README.md` และโฟลเดอร์ `lib/` `storage/`
- การตั้งค่าครั้งแรกต้องใช้ `setup_code` กันคนอื่นเปิดก่อนแล้วยึดบัญชีผู้ดูแล
- ครูแก้ค่าตั้งงานและจัดการบัญชีไม่ได้ · ลบหรือลดสิทธิ์บัญชีตัวเองไม่ได้

## รันในเครื่อง

ต้องมี PHP 8.1 ขึ้นไป พร้อม pdo_sqlite

```bash
git clone https://github.com/sricodeboon/kilasi.git
cd kilasi
php -S 127.0.0.1:8080
# เปิด http://127.0.0.1:8080/  (ไม่มี config.php ใช้ config.sample.php ซึ่ง setup_code ว่าง = ไม่ต้องใส่รหัส)
```

PHP built-in server ไม่อ่าน `.htaccess` การกันไฟล์ลับต้องตรวจบนโฮสต์จริง

## ขึ้นโฮสต์ (InfinityFree)

โฮสต์ไม่มี composer จึงติดตั้ง mPDF ในเครื่องแล้วอัปโหลดทั้ง `vendor/`

1. สร้าง `config.php` จาก `config.sample.php` แล้วตั้ง `setup_code` เป็นรหัสสุ่ม
2. สร้างไฟล์อัปโหลด (ติดตั้ง mPDF ตัดฟอนต์ที่ไม่ใช้จาก ~87MB เหลือ DejaVu แล้ว zip ~4MB)
   ```bash
   sh tools/build-zip.sh /path/to/composer.phar   # ได้ ../../kilasi.zip
   ```
   ไม่รวม `storage/` `config.php` README LICENSE `.git` `tools/` `composer.*`
3. File Manager → Upload & Unzip ในโฟลเดอร์ `/htdocs` (กดปุ่ม Upload & Extract ในหน้าต่าง) · ไฟล์ .php อัปแบบไฟล์เดี่ยวไม่ผ่าน ต้องใช้ zip
4. ตรวจว่า `/kilasi/config.php` `/kilasi/lib/` `/kilasi/storage/` `/kilasi/vendor/` เปิดจากภายนอกไม่ได้ (403) และไฟล์ใหม่เปิดได้ 200
5. การอัปเดตรอบต่อไปใช้ zip เดิม ไม่ทับ `storage/` (ฐานข้อมูลและไฟล์ชั่วคราวของ mPDF อยู่ใน `storage/`)

สำรองข้อมูล: ดาวน์โหลด `storage/kilasi.sqlite` จาก File Manager
